
# ProbandoBanner

A minimal MediaWiki extension that displays "Probando"
at the top of each page.

## Installation

1. Copy this directory into the MediaWiki extensions folder.
2. Add the following line to LocalSettings.php:

   wfLoadExtension( 'ProbandoBanner' );

3. Clear any relevant caches and reload the wiki.

## Requirements

MediaWiki 1.39 or later.
